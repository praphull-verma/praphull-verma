## Behind the API

> **What happens when two requests try to claim the same short URL?**
>
> Both can check the database and see that the code is available. A unique constraint gives the database the final say. The request that loses the race can retry with a fresh code.

That’s the kind of design question I enjoy. I’m exploring concurrency and system design, practising data structures and algorithms in Java, and building APIs with authentication and file uploads.
